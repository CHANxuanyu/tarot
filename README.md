# Tarot Oracles

Tarot Oracles is a static, multilingual tarot reading template built with React, TypeScript, and Vite. It is designed for developers and creators who want a polished tarot website that can be forked, customized, and deployed as a static site without a backend.

By default, readings are generated by a local structured reading engine and local data files. The default experience does not require an AI API, a server, a database, or environment secrets. Reports are symbolic, reflective interpretations based on tarot card data, spread positions, user questions, and locale-aware templates.

The project also includes an optional BYOK AI Enhanced Reading panel. Users may enter their own OpenAI-compatible API key in the browser to request an additional AI-generated interpretation. This feature is off by default; without an API key, the local structured reading engine remains fully available.

## Multilingual Support

The app currently supports:

- Simplified Chinese: `zh-CN`
- English: `en-US`
- French: `fr-FR`
- Spanish: `es-ES`

The i18n system is local and static:

- Locale state is managed in `src/i18n/I18nContext.tsx`
- Translation keys are defined in `src/i18n/index.ts`
- Locale files are stored in `src/i18n/locales/`

Fallback behavior:

- `zh-CN`: falls back to the translation key
- non-Chinese locales: current locale → `en-US` → translation key

This prevents French, Spanish, and English pages from accidentally falling back to Chinese UI copy.

## Optional BYOK AI Enhanced Reading

The default template works completely without AI. The AI Enhanced Reading panel is an optional browser-side BYOK feature.

How it works:

- The user enables AI reading manually from the result page.
- The user enters an OpenAI-compatible provider base URL, model, and API key.
- The app sends the current local reading report, spread information, drawn cards, locale, and user question to the provider.
- The AI response appears in a separate `AI Enhanced Reading` area.
- The local structured report remains visible and unchanged.

Security and deployment notes:

- No API key is included in this repository.
- No shared API key is required.
- API keys are stored only in the user's browser `localStorage`.
- API keys are not included in copy/export text or local reading history.
- Do not use sensitive organization-level keys in a browser-side BYOK flow.
- Browser-side provider calls are not a secure proxy. Requests go directly from the user's browser to the configured provider.
- Some providers may not support direct browser calls because of CORS restrictions.
- If no API key is provided, all local tarot readings still work normally.

AI output should be treated as optional reflective text. It is not a guarantee, professional advice, or a substitute for the local structured reading engine.

## How to Customize

You can customize the template by replacing local assets and data:

- Card artwork: `public/themes/classic-mystic/cards.json` and its referenced image paths
- Card meanings: `src/data/majorArcanaMeanings.ts`
- Spread definitions: `public/themes/classic-mystic/spreads.json`
- Theme metadata: `public/themes/classic-mystic/theme.json`
- Global visual tokens: `src/styles.css`
- UI translations: `src/i18n/locales/`
- Optional AI defaults and prompt boundaries: `src/core/AiReadingStorage.ts` and `src/core/AiReadingPrompt.ts`
- Zodiac coin icons: `public/assets/images/zodiac/`

See [`CUSTOMIZATION_GUIDE.md`](./CUSTOMIZATION_GUIDE.md) for details.

## Reading Engine Notes

Tarot Oracles uses a local static reading engine by default:

- No server-side generation
- No AI model calls required
- No online translation service
- No external reading API required

The local engine combines:

- Drawn card data
- Card orientation
- Spread position
- User question
- Question-domain detection
- Local Major Arcana meaning data
- Locale-aware report generation

This makes the template suitable for static hosting and predictable customization. The generated readings should be presented as symbolic guidance and reflective content, not as guaranteed predictions.

The optional BYOK AI panel can add a separate AI-generated interpretation when the user provides a compatible key. It does not replace the local engine and should not be presented as more certain than the structured report.
